# NPSP Workflow Replacements
This site guides Salesforce Admins using Nonprofit Success Pack in recreating legacy NPSP workflows as flows.  Either by downloading the package or using step-by-step flow building directions, you can recreate 4 Workflows:

# Project Overview
## Vision & Goals
* Design and document flows to replace all 20 NPSP (v3) and V4S workflow rules
* Create unmanaged packages with replacement flows
* Identify/document considerations for earlier NPSP flow versions

## Project Vertical
Nonprofit

## Trailblazer Group or Slack Channel Link (access required)
Slack Channel: osc-npsp-workflow-replacements https://salesforce.enterprise.slack.com/archives/C08JR0XFV7S

## How to Contribute:
- Editing Flows & Testing Various Pre-built Flows, Improving as needed
- Creating Video Documentation
- Creating Documentation and Flows in GitHub
- Documentation Writing / Standardization
  - Creating Documentation in Google Docs with Screenshots
  - Have written documentation for how to recreate the Flow in your own Org using the documentation
